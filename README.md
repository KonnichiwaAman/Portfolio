# Aman Awasthi Portfolio (Legacy)

An earlier personal portfolio application built with React, TypeScript, and Vite.

## Live site

[amaniaxportfolio.netlify.app](https://amaniaxportfolio.netlify.app)

## Status

This repository is retained for the currently deployed portfolio site. Active primary portfolio development occurs at [Aman-Portfolio](https://github.com/amandeavor/Aman-Portfolio).

## Technology

- React, TypeScript, and Vite
- Tailwind CSS and shadcn/ui components
- Framer Motion
- Jest and Testing Library configuration
- A small Node.js API server

## Local development

```bash
git clone https://github.com/amandeavor/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Run the local API server separately when required:

```bash
npm run api:dev
```

## Available commands

```bash
npm run lint
npm test
npm run build
npm run preview
```
