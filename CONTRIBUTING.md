# Contributing to Earlier Portfolio Application

This repository contains an earlier iteration of Aman Awasthi's portfolio website.

## Status

Active primary portfolio development occurs at [Aman-Portfolio](https://github.com/amandeavor/Aman-Portfolio). This repository is maintained strictly for legacy site deployment stability.

## Development

```bash
git clone https://github.com/amandeavor/Portfolio.git
cd Portfolio
npm install
npm run dev
```

## Quality Commands

```bash
npm run lint
npm test
npm run build
```
